# 01 要件と方針

## 目的
薩摩川内市の子育て支援センターは、施設ごとにイベント情報の出し方も予約方法もバラバラ（来所して予約表に記入、電話、施設独自のWeb予約・アプリ）。保護者は施設ごとにおたよりやInstagramを確認する必要がある。
市の「子育て支援カレンダー」も更新が止まっている。
→ **市内全センターのイベントを1か所で見られ、施設が自分で更新できる仕組み**を作る。

## 利用者
| 立場 | やりたいこと |
|---|---|
| 保護者 | 今日・近日のイベントを知る／子どもの月齢で参加できるものを探す／施設の情報（時間・場所・電話）を見る／予約する（フェーズ2） |
| 施設職員 | イベントを登録・修正する／おたよりやお知らせを載せる／臨時休所を知らせる／予約を確認する（フェーズ2） |
| 運営（れお） | 施設アカウントの発行／利用状況の確認（市への提案材料） |

## 対象施設（8か所）
すくすくランド、ほっとランド、すわっこ、ぱぴぃら、おいでおいで、スマイリィ、ぽけっと、てとて
（情報は `data/facilities.json`。開所時間は市の子育て応援ガイドと各おたよりを元にしたもの。おたよりの記載を優先）

### 予約方法の違い
| 種類 | 施設 | アプリでの扱い |
|---|---|---|
| `external_web` 独自のWeb予約 | スマイリィ、てとて | 「施設の予約ページへ」で外部リンク |
| `external_app` 独自のアプリ | ぽけっと、ぱぴぃら | 同上（URLがなければ電話番号を表示） |
| `onsite_or_phone` 来所記入・電話 | すくすくランド、ほっとランド | フェーズ2でこのアプリの予約機能を提供 |
| `phone` 電話 | すわっこ、おいでおいで | 同上 |

## フェーズ
| フェーズ | 内容 | 個人情報 | Supabase |
|---|---|---|---|
| 1 | イベント・施設・おたより・お知らせの閲覧／施設によるイベント登録 | なし（施設職員のログインのみ） | 無料（開発はローカル） |
| 1.5 | 施設の取材記事（インタビュー）・市の子育て講座の掲載 | なし | 無料 |
| 2 | 保護者の会員登録・予約・キャンセル／施設の予約管理・電話予約の手入力・予約通知メール | あり（保護者名・連絡先・子の呼び名と月齢） | 実運用の直前にPro |
| 3 | スタンプ・参加後アンケート・統計・CSV出力・お気に入り | あり | Pro |

各フェーズの終わりに、知人・施設に触ってもらって感想を集める。
営業はフェーズ2をダミーデータで動かした段階で行う（入力・確認・予約を実際に見てもらう）。

## 決定事項
- 子どもの体重・性格・生年月日は持たない。月齢のみ。
- アレルギー情報はアプリで持たない。食事系イベントでは「アレルギーのある方は事前に施設へお電話ください」と表示。
- 公開レビューは作らない。スタンプ（人気の目安）と、施設だけが読むアンケートにする。スタンプが少ないイベントを目立たなくする表示はしない。
- イベントは施設が手入力（前月コピー・毎週の繰り返し・テンプレートで手間を減らす）。PDFのAI読み取りはしない。
- AIは後から「今日のまとめ」「○○ある？」の検索に使う（フェーズ1の後半以降。まずは普通の絞り込みで作る）。
- 予約の画面は「今日のイベント中心」。美容院のような時間枠ではなく「定員○組・残り○組」で見せる。
- Supabaseは2プロジェクト構成（子育てアプリと習い事アプリを分ける）。有料化する組織は、補助金サイト・保育アプリとは別の組織にする。

## 差別化の方針（ジモイクとの違い）
1. 施設の今の予約方法を変えさせない（情報だけ1か所に集める）
2. 地元の制作者がすぐ直し、導入時は伴走する
3. 「今日、この子と行けるところ」がすぐわかる（月齢・臨時休所・駐車場）
4. 制作者のイラストによる温かい見た目
5. 大手が来にくい近隣の町への横展開

## コンテンツの方針
- 施設の取材記事はフェーズ1完了後（1.5）に追加。営業で施設を回る際に取材する。写真・似顔絵イラスト・「初めての方へ」（雰囲気・駐車場・持ち物）を載せる。掲載前に施設の確認を取る。
- 市の子育て講座（保健センター・SSプラザせんだい・センノオト等）は「市のイベント」として掲載可。乳幼児健診・予防接種の管理は扱わない（専用サービスへのリンクのみ）。
- 一般的な育児ハウツー（抱っこ・あやし方）は優先度低。載せる場合は施設の保育士さんの「ひとことコツ」として施設紹介とセットにし、医療的な内容は扱わない。

## 公開前に必要なこと
- 各施設からの掲載許可（許可前はデモとしてのみ使い、一般公開しない）
- 利用規約・プライバシーポリシー（フェーズ2開始前は必須）
- 施設向けマニュアル（作業ごとに1枚＋短い操作動画＋困ったとき1枚）
