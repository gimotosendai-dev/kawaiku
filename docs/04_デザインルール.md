# 04 デザインルール

## 方向性
- やわらかいパステル調。子育て中の保護者が、片手・短時間で見やすいこと。
- 文字は濃い色。パステルは背景・カード・タグ・枠に使う。
- ロゴ・キャラクターは制作者（れお）が後で描く。最初は仮の文字ロゴでよい。
- 競合サービスの配色・レイアウトをそのまま真似しない。

## CSS変数（`src/styles/tokens.css`）
**色や大きさは必ずここで管理する。** 他のCSSでは `var(--color-...)` のように変数を使う。
以下は初期値。大枠ができたら制作者が調整する。

```css
:root {
  /* 基本の色 */
  --color-bg: #fffaf5;          /* 背景（クリーム） */
  --color-surface: #ffffff;     /* カード */
  --color-text: #3d3a37;        /* 本文（濃いグレー） */
  --color-text-sub: #6f6a65;    /* 補足文字 */
  --color-border: #ece4da;
  --color-primary: #a7634d;     /* メインのボタン（テラコッタ。白文字が読める濃さ） */
  --color-primary-text: #ffffff;
  --color-accent: #8cc7b5;      /* アクセント（ミント） */
  --color-alert-bg: #fff1c9;    /* 臨時休所の帯 */
  --color-alert-text: #7a5a00;

  /* 施設の色（背景用のパステル / 文字・線用の濃い色） */
  --facility-mint: #dff3ea;     --facility-mint-strong: #33755e;
  --facility-peach: #ffe4d8;    --facility-peach-strong: #a25034;
  --facility-lemon: #fff4c2;    --facility-lemon-strong: #816d00;
  --facility-lavender: #ebe3f7; --facility-lavender-strong: #6b54a3;
  --facility-sky: #dcefff;      --facility-sky-strong: #2e6ca4;
  --facility-pink: #ffe3ec;     --facility-pink-strong: #a94468;
  --facility-apricot: #ffead1;  --facility-apricot-strong: #975919;
  --facility-sage: #e6efdc;     --facility-sage-strong: #557238;

  /* 文字 */
  --font-family: "Hiragino Maru Gothic ProN", "M PLUS Rounded 1c", "Hiragino Sans", sans-serif;
  --font-size-xs: 12px;
  --font-size-sm: 14px;
  --font-size-md: 16px;   /* 本文は16px以上 */
  --font-size-lg: 19px;
  --font-size-xl: 23px;

  /* 形 */
  --radius-sm: 8px;
  --radius-md: 16px;
  --radius-lg: 24px;
  --radius-pill: 999px;
  --shadow-card: 0 2px 10px rgba(80, 60, 40, 0.08);

  /* 余白 */
  --space-1: 4px;
  --space-2: 8px;
  --space-3: 12px;
  --space-4: 16px;
  --space-5: 24px;
  --space-6: 32px;

  /* 押せる場所の最小の高さ */
  --tap-min: 44px;
}
```

**読みやすさのルール**：文字と背景の明るさの差（コントラスト比）は4.5以上にする。上の初期値は確認済み。色を変えるときは、ブラウザの開発者ツールなどでコントラスト比を確認する。

施設色の使い方：`facilities.json` の `color: "mint"` → `--facility-mint`（カード上部の帯・タグの背景）と `--facility-mint-strong`（施設名の文字）。

## 部品
| 部品 | ルール |
|---|---|
| イベントカード | 上部に施設色の帯＋施設名、イベント名（太字）、日時、対象月齢タグ、「要予約」「定員○組」タグ。写真がなければジャンルのアイコンを表示 |
| タグ | 角丸ピル型。対象月齢・要予約・定員・駐車場混雑 |
| ボタン（主） | `--color-primary`、高さ `--tap-min` 以上、角丸 `--radius-pill` |
| 下部ナビ | ホーム／さがす／予約一覧（フェーズ2）。アイコン＋文字 |
| 臨時休所の帯 | トップ最上部。`--color-alert-bg` |
| 施設リスト | 施設色の丸＋施設名＋開所時間＋電話ボタン |

## 表示のきまり
- 日付：`11月25日（水）`
- 時間：`10:30〜11:30`
- 月齢：`0〜11か月`／`1歳〜`／`1歳2か月〜`／制限なしは `どなたでも`
- 定員：`定員7組`（フェーズ2で `残り3組`）
- 料金：0円は `無料`、null は `料金は当日ご確認ください`
- スタンプの人気表示（フェーズ3）：多いほど少し目立つ飾り。少ないイベントを目立たなくはしない
