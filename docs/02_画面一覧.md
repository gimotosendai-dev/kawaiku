### 予約ボタンの出し分け（イベント詳細）
| 条件 | 表示 |
|---|---|
| `reservation_required = false` | 「予約不要・直接どうぞ」（ボタンではなく表示のみ） |
| 施設が `external_web` / `external_app` で URL あり | 「施設の予約ページへ」→外部リンク |
| 施設が `external_*` で URL なし | 「施設のアプリで予約できます」＋電話ボタン |
| 施設が `phone` / `onsite_or_phone`（フェーズ1） | 「お電話で予約」＋電話ボタン |
| 同上（フェーズ2以降） | 「予約する」→ 画面4へ |
| 食事系（category = `food` など） | 「アレルギーのある方は事前に施設へお電話ください」を表示 |
