# 05 進め方とプロンプト

Claude Codeに渡す指示文を、作る順番に並べたもの。**1ステップずつ**進め、動作を確認してから次へ。
各ステップの最後に、スマホで見て気づいたことをメモしておく（AI教室・Instagram発信の材料になる）。

---

## ステップ0：準備（れおさんが手で行う）
1. 新しいGitHubアカウントで、非公開（Private）のリポジトリを作る（例：`kosodate-center-app`）
   - 施設の掲載許可が取れるまでは非公開にしておく
2. このフォルダの中身（`CLAUDE.md`、`docs/`、`data/`）をリポジトリに入れる
3. リポジトリから Codespaces を開く
4. ターミナルで `claude` を起動し、Claudeのアカウントでログインする

---

## ステップ1：土台づくり
```
CLAUDE.md と docs/ をすべて読んでから始めてください。
Vite（フレームワークなし）でプロジェクトの土台を作ってください。
- CLAUDE.md のフォルダ構成に合わせる
- src/styles/tokens.css に docs/04_デザインルール.md のCSS変数を入れる
- src/data/ に data/*.json を読み込む関数を作る（後でSupabaseに差し替えられる形）
- ハッシュルーティング（#/ や #/event/ev001）で画面を切り替える仕組みだけ作る
- 開発サーバーを起動して、スマホで確認する方法も教えてください
```
確認：開発サーバーの画面が開く。`#/` と `#/event/ev001` で表示が変わる。

## ステップ2：トップ画面
```
docs/02_画面一覧.md の「1 トップ」を作ってください。
- 今日のイベント（横スライド）、近日のイベント（2列）、お知らせ、おたより、支援センター一覧、フッター
- 「今日」は ?date=2026-11-25 で変えられるようにする
- 臨時休所があればトップに帯で表示する
- 色は tokens.css の変数だけを使う
```
確認：`?date=2026-11-25` と `?date=2026-11-24` で表示が変わる。ほっとランドの臨時休所（11/26）の帯が出る。

## ステップ3：イベント詳細
```
docs/02_画面一覧.md の「2 イベント詳細」を作ってください。
予約ボタンは「予約ボタンの出し分け」の表のとおりに表示を変えてください（フェーズ1なので、自前予約の施設は「お電話で予約」）。
対象月齢・料金・日付の表示は docs/04_デザインルール.md の「表示のきまり」に合わせてください。
```
確認：てとて（外部予約）、すくすくランド（電話）、予約不要のイベントで、ボタンが変わる。

## ステップ4：支援センター詳細・おたより・お知らせ
```
「支援センター詳細」「おたより」「お知らせ詳細」の画面を作ってください。
電話番号はタップで発信、住所はタップで地図アプリが開くようにしてください。
```

## ステップ5：さがす・イベント一覧
```
「8 さがす（ボトムシート）」と「9 イベント一覧」を作ってください。
絞り込み：日付、施設、ジャンル、子どもの月齢（例：1歳3か月 → その月齢で参加できるイベント）、予約不要のみ。
```
確認：月齢を「5か月」にすると、1歳以上限定のイベントが出ない。

## ステップ6：PWA化
```
vite-plugin-pwa でホーム画面に追加できるようにしてください。アイコンは仮でよいです。
```
→ ここで一度、知人に触ってもらう（フェーズ1の利用者側が完成）

## ステップ7：ローカルのSupabase
```
Supabase CLI でローカルのSupabaseを立ち上げてください。手順を一つずつ説明してください。
docs/schema.sql でテーブルを作り、data/*.json のダミーデータを入れてください。
src/data/ の読み込み先を、JSONからSupabaseに切り替えられるようにしてください（設定で切り替え）。
```

## ステップ8：施設側（ログイン・ダッシュボード・イベント登録）
```
docs/02_画面一覧.md の施設側フェーズ1の画面を作ってください。
まずはログイン、ダッシュボード、イベント登録（新規）、プレビュー、イベント一覧・編集から。
職員は自分の施設のデータだけ編集できるようにしてください（schema.sql のRLS）。
```

## ステップ9：施設側の入力を楽にする
```
イベント登録に「テンプレートから作る」「前月のイベントをコピー」「毎週の繰り返し」を追加してください。
お知らせ投稿、おたよりPDFのアップロード（Supabase Storage）、臨時休所の登録も作ってください。
```
→ フェーズ1完成。知人・協力してくれる園に触ってもらう

## ステップ10：取材記事（フェーズ1.5）
```
docs/02_画面一覧.md の「取材記事一覧」「取材記事詳細」と、運営側の記事作成画面を作ってください。
docs/03_データ設計.md の articles テーブルを追加し、トップに新着記事を表示してください。
記事は「下書き → 施設確認中 → 公開」の順で状態を変えられるようにしてください。
```
